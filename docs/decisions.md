## D-001 规划经理如何澄清出行需求

- **日期与状态**：2026-09-13；已确认（选 B）
- **关联**：REQ-001；规划经理职责（了解需求后出推荐计划或追问）
- **问题与体验影响**：问少了方案会拍脑袋；问多了客户会不耐烦。国内和出境的风险不同，不能用同一张必填表卡死。

### 0. 调研：专业规划师到底要先知道什么

本次要决定：第一期规划经理在什么信息下直接出推荐计划，什么情况下只追问一轮；国内 / 出境是否分流。对比的是「接单问诊」而不是订票后台。

| 比较项 | 欧洲定制顾问（奥利） | 国内旅行社定制表（康辉等） | 对应来源 |
| --- | --- | --- | --- |
| 目标用户 | 还没有完整行程、只有几个关键词的客人 | 国内游 / 出境游分开填写的定制客人 | S1、S3 |
| 核心流程 | 先给人数、月份、天数、进出城市、想去的地方 → **判断这趟能不能这样走** → 再匹配或定制，最后才细化报价 | 先填目的地、**出发地点**、天数、人数、预算 → 再往下谈餐标住宿 | S1、S3 |
| 最小信息 | 官方写明：还没有完整行程也可以；最重要的是人数、日期/天数、进出城市、目的地方向、预算；带老人孩子要提前说 | 目的地必填、出发地点必填；人均预算、时长、成人/儿童 | S1、S3 |
| 出境相对国内多出来的 | 进出机场、跨国衔接、用车；签证材料是代订/代办阶段的事，不是第一份路线判断的前提 | 出境申请/签证表才会要护照号、签发地等（代办签证） | S1、S4 |
| 国际旅行顾问问卷（第三方） | 预算要给区间且说清含什么；风格、日期是否可挪、健康行动不便 | 护照有效期、签证用于**下单和入境**，不是出第一份推荐行程的前置 | S2、S5 |

| --- | --- | --- | --- |
| S1 | [定制行程 \| 奥利｜法国与欧洲旅行](https://aolitravel.com/custom-travel/) | 2026-09-13 | 官方正文：最小信息、先判断路线再细化 |

| S4 | [出境旅游申请表-携程旅游](http://vacations.ctrip.com/notes/1268.html) | 2026-09-13 | 仅搜索摘要：护照字段出现在签证申请表，不是行程创意阶段 |
| S5 | [The Ultimate Travel Agent Client Questionnaire](https://ica-mi.org/wp-content/cache/blogs/travel_agent_client_questionnaire.html) | 2026-09-13 | 仅搜索摘要：风格、预算区间、日期是否可挪 |

**和本项目的关系：** 第一期不做订票、不做代办签证，规划经理的任务是**快速出一份可改的推荐计划**。对齐「判断路线」那一步（S1），而不是签证申请表（S4）。出发城市、预算、天数、和谁、想怎么玩是开工最小集；护照号、紧急联系人第一期不收集。

### 1. 建议的工作方式：先判断，再出计划或追问

专业规划师不会等 20 个字段齐了才说话。他先看：**这趟在时间和钱上能不能成立**，能就出一版推荐，不能就只问卡住的那一两句。

| 可选方案 | 客户体验 |
| --- | --- |
| A. 国内境外同一张长表，填齐再规划 | 出境被国内字段打扰，国内被签证字段打扰 |
| B. 先收「开工最小集」，按国内/出境分流；够了就出推荐计划，不够就最多追问 2 轮（推荐） | 像顾问：模糊描述也能往下走 |
| C. 不限轮次问到全部选填 | 出方案太慢 |

- **已确认选 B，并锁定流程：** 规划经理通过**多轮对话逐渐收敛**需求；**专员在最小集未齐时不上场**。最小集齐了（或客户说「先按现在这样出一版」且最小集已齐）后，进入 Multi-Agent（目的地研究、预算专家、行程设计）输出旅行计划。
- **第 0 轮**：客户给出当前位置、预算、节奏、模糊愿望（可以没有精确城市）。
- **判断**：按第 2 节的最小集，决定是进入 Multi-Agent，还是追问。
- **第 1 轮追问**：只问当前路径上还缺的、会改变推荐的项，一次问完。
- **第 2 轮**：仅矛盾或仍缺最小集时。
- 2 轮后最小集仍不齐：不出假计划，说明还缺什么。客户也可在最小集已齐时主动要求出初稿。

### 2. 开工最小集（有了就可以出第一份推荐计划）

这五件事齐了，规划经理就应该尝试出计划，而不是继续盘问。模糊可以，但不能全空。

| 字段 | 为什么规划师必须先知道 | 允许的模糊程度 |
| --- | --- | --- |
| 客户当前位置 / 出发城市 | 决定怎么去、第一天是否浪费在路上、预算里要不要极大交通。国内社把出发地当必填（S3）；欧洲定制把进出城市当判断路线的核心（S1） | 到地级市即可，如「上海」 |
| 国内还是出境 | 签证、大交通、时差、清单完全不同，不能混用一张必填表 | 有明确城市则可推断；只有「出去玩」则第 1 轮必须问清 |
| 时长 | 没有天数无法排天；定制顾问把天数/月份当最小信息（S1） | 天数或「大概哪个月、玩几天」 |
| 和谁 | 人数+构成（情侣/亲子/家庭/个人）。带老人小孩会改节奏（S1） | 「带老婆」可推断 2 人情侣，规划师复述确认即可，不必再开一轮 |
| 预算 | 判断想要的玩法是否撑得住（S1）；要有数字或档位，并默认写清含什么 | 「2 万」或「舒适档」；不填数字时用档位 |
| 节奏 + 旅行的模糊描述 | 节奏是疏密；模糊描述是内容（想看海、想吃、京都、不想太累） | 可以没有精确景点；但不能既没有目的地也没有画面（「随便」且国内境外都未选） |

有了上面这些，**即使没有精确日期、没有交通偏好、没有住宿档次**，也可以出第一份推荐，并在方案里写明假设（例如市内按公交+步行、主题按模糊描述推断）。

### 3. 国内 / 出境：必填和追问怎么分

先判定路径：客户说了城市则推断；没说则问「这次是国内还是出境」。

**国内游——有出发地、时长、和谁、预算、节奏、模糊描述即可出计划。**

| 情况 | 规划经理怎么做 |
| --- | --- |
| 已有城市（如成都 5 天） | 直接出计划，不必再问国家 |
| 只有画面没有城市（「想看海、带小孩、从北京出发、4 天、预算 8 千、别太赶」） | **可以直接推荐 1 个目的地并出计划**（如青岛/北戴河之一），并说明为什么选这里；不要先逼客户点出一个市 |
| 天数和距离明显冲突（哈尔滨出发玩海南只要 2 天） | 追问：加天，还是改近处，还是接受大半时间在路上 |
| 交通、住宿、必去景点未说 | 不挡出计划；用默认并写在方案里。客户改稿时再调 |

国内第一期**不问**：护照、签证、国际漫游。清单里可有身份证、高峰车票等。

**出境游——同样要出发地、时长、和谁、预算、节奏、模糊描述；目的地至少到国家或明确区域。**

| 情况 | 规划经理怎么做 |
| --- | --- |
| 已有城市或国家（京都 / 日本） | 可以出计划 |
| 只说「想出国」，没有国家或区域 | **必须追问一轮**：日韩 / 东南亚 / 欧洲等，或让客户补一个画面（樱花、海滩、城市散步）。未选出境方向前不出完整按天计划 |
| 预算明显只够国内但选了欧洲 | 追问：加预算、缩短天数、或改近途出境（如日韩） |
| 护照签证 | 第一期**不收集护照号**。出境方案的行前清单提示护照有效期、是否可能要签证；客户说「没有护照」则追问能否换成国内，或标明「需先办证件，本期只给行程草案」 |

出境相对国内，规划师多要判断的是：国际机票是否含在预算里、首尾两天进机场、时差是否要留白。这些在第 1 轮用 **1～2 个问题**问，不要开签证表。

### 4. 完整盘点（专业规划师会关心，但不都是开工条件）

仍按顾问习惯列全，避免漏项；第一期用法见第 2～3 节。

**去哪、何时、从哪走：** 出发城市（必有）；国内或出境（必有或可推断）；目的地城市/国家/或模糊画面；是否多城（第一期建议一个主要目的地）；天数或月份；具体日期（有则更好，没有用第 1～N 天）；机票酒店是否已订（有抵达时间则写入首尾天，第一期不代订）。

**和谁：** 人数、人群类型、儿童年龄段（亲子条件必问）、老人或行动不便、纪念日（选填）。

**钱：** 总价或人均或档位；是否含大交通/住宿。出境默认追问一句「预算含不含国际机票」；国内默认含国内大交通+当地花费，客户可改口径。

**怎么玩：** 节奏（必有）；旅行方式/主题（可用模糊描述代替，不必另填）；初访/重游、网红/小众（选填）。

**怎么走：** 多走路 / 公交 / 打车 / 包车 / 混合。不够也不挡第一份计划，默认「国内城市：公交+适量步行；出境同，除非客户说少走路」。

**住与吃、硬性约束：** 住宿档次、忌口、必去/不去。选填。

**第一期不当独立问题：** 护照号、签证材料、保险、紧急联系人、支付方式。出境只在清单层提示证件，不在问诊层收敏感证件号。

### 5. 第 1 轮追问示例

客户在上海：「想带老婆玩 5 天，预算 2 万，不要太赶，想轻松吃吃走走。」

缺的是国内还是出境、以及画面落在哪类地方。一轮即可：

> 按情侣、5 天、2 万、轻松节奏来。还差一件就能出计划：这次是**国内**还是**出境**？更想看海、逛古城，还是日韩这种近途出国？有倾向我就按那个出一版，交通按公交和多走路来排，你可以再改。

若客户答「京都」：最小集已齐（出发上海、出境、5 天、情侣 2 人、2 万、自由探索、京都），**不再追问**，直接派专员出计划。

- **最终选择与确认依据**：用户 2026-09-13 确认。规划经理多轮对话收敛；拿到足以生成方案的内容支撑后，再进入 Multi-Agent 输出旅行计划。国内可按模糊描述推荐目的地；出境须先有国家/区域；出发地、预算、节奏、模糊描述纳入最小集；不收集护照号，出境仅在清单提示证件。

## D-006 节奏分档与行程详情按日滚动

- **日期与状态**：2026-09-13；已确认
- **关联**：REQ-004、REQ-005、REQ-006；新建计划表单
- **问题与体验影响**：原先只有「快速 / 自由探索」，表单不好选，和市面上说法也对不齐。行程若只有长列表、不能按天跳，客户很难看「那天去哪、中间怎么走」。

**节奏怎么分（公开说法归纳，不是精确算法）：**

英文行程工具常用 relaxed / moderate / packed（每天大约 2–3、3–5、6+ 个活动，见 Yopki 一类规划说明）。中文语境里是轻松/慢游、适中/快慢结合、紧凑/打卡；「特种兵」属于紧凑里的口语，中青校媒调查里不少人用过但更倾向快慢结合。路书类实现也有轻松/适中/紧凑三档（按每天地点上限），分钟数本期不验收。

| 表单选项 | 口语可映射 | 排法（可观察，不验分钟） |
| --- | --- | --- |
| 轻松 | 不要太赶、自由探索、慢充 | 每天大约 1–2 个主要点，多留白 |
| 适中 | 一般、快慢结合 | 每天大约 2–3 个点 |
| 紧凑 | 快速、打卡、特种兵 | 每天大约 3–4 个点 |

**行程详情（借鉴按日滚动的行程 App 信息结构，不复制其账单/相册）：** 顶部日期可点；上下滚动时当前日期跟着变；卡片之间展示推荐交通与大约距离/时间；点卡片看景点或推荐住宿的简介。不做支出金额、旅行账单、相册；不强制跳转外部导航 App。

- **最终选择与确认依据**：用户 2026-09-13 要求表单加上节奏，并指定按日期滚动 + 交通 + 卡片微详情。
